Add your age public key

Passwords are encrypted to this key. Only the matching private key, kept on your own device, can read them.

  1. On your computer, run age-keygen -o ~/.config/age/pwgen.txt
  2. Paste the public key it prints, starting with age1. Add a backup key on a second line if you have one.

Your public keys changed
